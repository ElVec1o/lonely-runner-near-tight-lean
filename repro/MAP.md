# Map from statements to Lean declarations

Status as of 2026-11-25. Conventions: `N` is the number of speeds (the runner at rest is not counted), `Sext6.LRC m` says that `m` distinct positive speeds have `ML >= 1/(m+1)`, `ML` is `sSup` of the gap function in Lean. `g_N` is the least value of `ML` above `1/(N+1)` over `N`-sets; `G(N)` is the minimum of the one-entry family value; they are different objects (`g_N <= G(N)` only).

Column "Saved output": the file of `expected_output/` (the name of the saved Lean build log, extension `.axioms.txt`) that holds the `#print axioms` lines. "std" means that every printed line is a subset of `[propext, Classical.choice, Quot.sound]`; no `sorryAx` and no `ofReduceBool` occurs in any saved output (`expected_output/SUMMARY.tsv`, checked by `judge_axioms.sh`).

Label used here: "Lean" means that the saved build log of the author's development tree ends with `Build completed successfully` and prints the axiom lines listed; it does not mean that the statement was reviewed by a human or that this repository has been built from a clean checkout (it has not).

The authoritative map from paper numbering to declarations is the table "Status per statement" of each paper (A1: `paperA1`, A2: `paperA2`, B: `paperB`). The table below is organised by Lean module.
